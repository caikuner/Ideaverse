### px rpx em rem vw/vh % 区别

**px** 像素，绝对长度单位。它是图像显示的基本单元，但既不是一个确定的物理量，也不是一个点或者小方块，而是一个抽象概念。就是说，px 是逻辑像素，也常被称为 CSS 像素。而逻辑上的 1px 显示到设备上时，就会根据设备屏幕的设备像素比（DPR，只与设备的硬件密度有关）映射为设备像素【物理像素】。

DPR = window.devicePixelRatio, 通常在 PC 端，dpr=1, 所以 1px 显示到电脑上看起来就是固定的 1px。不过像移动端这样的小屏高清设备，dpr 可能为 2、3，就会显示为 2px、3px 的大小。怎么办呢？

- 获取 dpr 值，比如为 2
- 设置 viewport： <meta name="viewport" content="width=device-width, initial-scale=0.5, maximum-scale=0.5, minimum-scale=0.5, user-scalable=no"/>
- 设置对应 viewport 的 rem 基准值： html{ font-size: 10 px }

后面想设置 10px 就是 1rem，这 1rem 是逻辑 10px，而这 10px 在移动端被 dpr=2 放大为 20px，又被 viewport 缩小为 10px

**rpx** 是微信小程序独有的、解决屏幕自适应的尺寸单位

可以根据屏幕宽度进行自适应，不论大小屏幕，规定屏幕宽为 750rpx

通过 rpx 设置元素和字体的大小，小程序在不同尺寸的屏幕下，可以实现自动适配

**em**

相对长度单位，em 是相对于当前元素的父元素的 font-size 进行计算，如果当前元素未设置则相对于浏览器的默认字体尺寸。

**rem**

相对长度单位，CSS3 新增的一个相对单位，rem 是相对于根元素 (html) 的 font-size 进行计算，rem 不仅可设置字体大小，也可以设置元素宽高属性。大

**vw/vh**

vh 相对于视窗的高度，视窗高度是 100vh

vw 相对于视窗的宽度，视窗宽度是 100vw

这里是视窗指的是浏览器内部的可视区域大小，即 `window.innerWidth/window.innerHeight` 大小，不包含任务栏标题栏以及底部工具栏的浏览器区域大小。

### **百分比**参照值

设置宽高、定位等属性时我们常常会设置相对值百分比，那这个百分比的参照值是什么呢？

主要有三种：包含块、元素自身、继承值。

**参照包含块 (正常时父元素)**

- **定位** 参照包含块，其中上下参照包含块高度，左右参照块的宽度
- static & relative : 没有脱离正常流，所以包含块是**父元素的内容区域**
- absolute : 包含块是第一个 position 不为 static 的祖先元素【就是子绝父相的那个 ' 相 '】**的内容区域；注意如果没有这样的祖先，那包含块是** **初始包含块 body？**
- fixed : 包含块就是视口
- **宽高** 参照包含块，其中宽参照包含块的宽，高参照块的高
- 宽比较简单，找父元素的宽就好。由于块级元素已经默认设置宽度 100%、行内块一般会有自身内容的宽高，所以正常找就好
- 但是有的包含块 (父) 并没有明确的设置高度，全靠内容撑起来，这时候再参照这个高度就失效了。所以高度的情况：
- 包含块设置了高度就相对于块的高度
- 包含块没有明确高度，就会导致结果为 `height: auto`
- 另外，由于根元素 html 的包含块是视口，有高度，所以给 html 设置百分比总会生效
- 内外边距 padding top 各自四个方向的值都是参照**包含块的宽度**，即使上下方向的 x-top/x-bottom 也是相对于**块的宽度！【注意】**
- 缩进 text-indent 参照包含块的宽度

**参照元素自身**

- **边框圆角 border-radius** 参照元素自身的尺寸，其中圆角的水平半径参照宽，垂直半径参照高
- **位移 translate** 参照元素自身的尺寸，注意是盒模型的尺寸【标准还是怪异是不同的】

**参照继承值**

字体相关的会参照继承值【是绝对值】

- font-size
- line-height : 行高本来就是按照字体大小计算的，所以子元素的行高会相对于继承过来的父元素字体大小【而不是父的行高】

```
div{
  font-size:18px;
  line-height:14px;
}
div > p{
  line-height: 50%; // 计算为 9px,而不是 7px！！
}
```

vertical-align 的百分比值是相对于 line-height 计算的
