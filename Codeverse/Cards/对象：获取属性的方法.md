### 获取对象原型链属性的方法

#### for…in

以**任意顺序**遍历一个对象的除 Symbol 以外的可枚举属性**（包括原型链上的和自己的）**

```javascript
const obj = { a: 1 };
Object.setPrototypeOf(obj, { b: 2 });

for (const key in obj) {
}
```

### 获取对象自身属性（非原型链属性）的方法

获取对象自身的属性（不包括从原型链继承的属性）：

#### 1. `Object.keys()`

返回对象自身可枚举属性的数组

```javascript
const obj = { a: 1, b: 2 };
Object.setPrototypeOf(obj, { c: 3 });

console.log(Object.keys(obj)); // ['a', 'b']
```

#### 2. `Object.getOwnPropertyNames()`

返回对象自身所有属性（包括不可枚举属性）的数组

```javascript
const obj = {};
Object.defineProperty(obj, "a", { value: 1, enumerable: true });
Object.defineProperty(obj, "b", { value: 2, enumerable: false });

console.log(Object.getOwnPropertyNames(obj)); // ['a', 'b']
```

#### 3. `Object.getOwnPropertySymbols()`

返回对象自身的 Symbol 属性

```javascript
const sym = Symbol("mySymbol");
const obj = { [sym]: "value" };

console.log(Object.getOwnPropertySymbols(obj)); // [Symbol(mySymbol)]
```

#### 4. `Reflect.ownKeys()`

返回对象自身所有键（包括 Symbol 和不可枚举属性）

```javascript
const sym = Symbol("sym");
const obj = {};
Object.defineProperty(obj, "a", { value: 1, enumerable: false });
obj[sym] = "symbol";
obj.b = 2;

console.log(Reflect.ownKeys(obj)); // ['a', 'b', Symbol(sym)]
```

#### 5. `for…in` + `hasOwnProperty()`

传统方法，需要配合检查

```javascript
const obj = { a: 1 };
Object.setPrototypeOf(obj, { b: 2 });

for (const key in obj) {
  if (obj.hasOwnProperty(key)) {
    console.log(key); // 'a'
  }
}
```

#### 6. `Object.hasOwn()` (ES2022)

更安全的检查自身属性的方法

```javascript
const obj = { a: 1 };
Object.setPrototypeOf(obj, { b: 2 });

console.log(Object.hasOwn(obj, "a")); // true
console.log(Object.hasOwn(obj, "b")); // false
```

### 方法对比

| 方法                             | 可枚举属性           | 不可枚举属性 | Symbol 属性 | 原型链属性 |
| -------------------------------- | -------------------- | ------------ | ----------- | ---------- |
| for in                           | ✅                   | ❌           | ❌          | ✅         |
| `Object.keys()`                  | ✅                   | ❌           | ❌          | ❌         |
| `Object.getOwnPropertyNames()`   | ✅                   | ✅           | ❌          | ❌         |
| `Object.getOwnPropertySymbols()` | ❌                   | ❌           | ✅          | ❌         |
| `Reflect.ownKeys()`              | ✅                   | ✅           | ✅          | ❌         |
| `for in` + `hasOwnProperty`      | ✅                   | ❌           | ❌          | ❌         |
| `Object.hasOwn()`                | 检查单个属性是否存在 |              |             |            |

#### 最佳实践

1. 如果需要获取**所有自身属性**（包括不可枚举和 Symbol），使用 `Reflect.ownKeys()`
2. 如果只需要**可枚举的自身属性**，使用 `Object.keys()`
3. 检查单个属性是否存在，优先使用 `Object.hasOwn()`（比 `hasOwnProperty` 更安全）
4. 如果需要包含不可枚举属性但不包括 Symbol，使用 `Object.getOwnPropertyNames()`
