浏览器网页性能指标是衡量用户体验和优化方向的关键数据，以下是现代 Web 开发中最常用的核心性能指标及其测量方式：
- LCP：视口中最大内容元素（如图片/标题）的渲染时间
- FID：首次可交互时间 => INP(平均可交互时间)
- CLS: 页面元素抖动偏移
- FCP：首次文本/图像内容渲染时间
- TTI：完全可交互时间，fcp 后，5s 无长任务（50ms）
- FPS：帧率

---

### **关键性能指标（Core Web Vitals）：LCP INP CLS**

Google 定义的三大核心指标：

1.**LCP (Largest Contentful Paint)**
- **定义**：页面中最大内容元素（如图片、标题文本块）完成渲染的时间，反映用户感知的“内容可见速度”。
- **重要性**：直接影响用户对页面加载快慢的第一印象，是 Google 核心 Web 指标之一。
- **推荐标准**：≤2.5 秒（良好），>4 秒（需优化）。
- **测量方式**：
    - **实验室工具**：Lighthouse、WebPageTest。
    - **真实用户监控（RUM）**：通过 `PerformanceObserver`API 捕获。

     ```javascript
     new PerformanceObserver((entryList) => {
       const entries = entryList.getEntries();
       console.log('LCP:', entries[entries.length - 1]);
     })
     .observe({ type: 'largest-contentful-paint', buffered: true });
     ```

2.**FID (First Input Delay)** => INP
- **定义**：用户首次与页面交互（如点击按钮）到浏览器实际响应的延迟时间，衡量交互流畅度。
- **重要性**：反映页面可交互性，延迟过高会导致用户认为页面“卡顿”。
- **推荐标准**：≤100 毫秒（优秀），>300 毫秒（需优化）。
- **测量方式**：
  - **RUM**：使用 PerformanceObserver
  - **替代指标**：INP（Interaction to Next Paint）未来将取代 FID。

     ```javascript
     new PerformanceObserver((entryList) => {
       const entries = entryList.getEntries();
       entries.forEach(entry => {
         console.log('FID:', entry.processingStart - entry.startTime);
       });
     }).observe({ type: 'first-input', buffered: true });
     ```

2023 年 google 改进了这一指标，修改为 **INP（Interaction to Next Paint，交互到下一绘制）**:
测量用户所有交互（包括点击、滚动、输入）从触发到页面首次视觉更新的平均时间。
优秀：≤200ms，需要优化：≥500ms


3.**CLS (Cumulative Layout Shift)**
- **定义**：量化页面渲染期间元素意外偏移的频率和幅度（如广告插入导致内容下移）。
- **重要性**：影响用户体验稳定性，Google 核心 Web 指标之一。
- **推荐标准**：≤0.1（良好），>0.25（需优化）。
- **测量方式**：
   - **工具**：Lighthouse、Chrome DevTools 的 Performance 面板。
   - **代码监控**：通过 PerformanceObserver `LayoutShift` API 计算偏移分数

     ```javascript
     let clsValue = 0;
     new PerformanceObserver((entryList) => {
       entryList.getEntries().forEach(entry => {
         clsValue += entry.value;
       });
       console.log('CLS:', clsValue);
     }).observe({ type: 'layout-shift', buffered: true });
     ```

### **加载阶段指标 FP FCP TTI TBT**

1. **FP (First Paint)**
   - **定义**：首次像素渲染时间（白屏→任何内容）
   - **优化建议**：减少**阻塞**渲染的 CSS/JS

2. **FCP (First Contentful Paint)**
   - **定义**：首次文本/图像内容渲染时间
   - **测量 API**：

     ```javascript
     performance.getEntriesByName('first-contentful-paint')[0].startTime
     ```

3. **TTI (Time to Interactive)**
   - **定义**：测量页面从开始加载到完全可交互（主线程空闲、事件可响应）的时间。
   - **重要性**：标识用户何时能顺畅操作，尤其关键于单页应用（SPA）。
   - **推荐标准**：≤3.8 秒（良好），>5 秒（需优化）。
   - **测量方式**：
      - **实验室工具**：Lighthouse、WebPageTest。
      - **计算逻辑**：首次内容渲染（FCP）后，主线程连续 5 秒无长任务（>50ms）。

4. **Total Blocking Time (TBT)**

- **定义/用途**：统计 FCP 到 TTI 之间主线程被长任务（>50ms）阻塞的总时间，影响交互响应。
- **重要性**：揭示 JavaScript 执行效率，长任务会导致输入延迟。
- **推荐标准**：≤200 毫秒（良好），>600 毫秒（需优化）。
- **测量方式**：
    - **实验室工具**：Lighthouse。
    - **长任务检测**：通过 `PerformanceObserver` 监听 `longtask` 事件（>50ms）。

     ```javascript
     new PerformanceObserver((list) => {
       list.getEntries().forEach(entry => {
         console.log('Long Task:', entry.duration);
       });
     }).observe({ entryTypes: ['longtask'] });
     ```

### **渲染性能指标 FPS**

**Frames Per Second (FPS)**

- **定义/用途**：测量每秒渲染的帧数，反映动画和交互的流畅度。
- **重要性**：低 FPS 会导致卡顿，影响用户体验，尤其在滚动、动画等场景。
- **推荐标准**：≥60 FPS（流畅），<30 FPS（明显卡顿）。
- **测量方式**：
    - **Chrome DevTools**：Performance 面板的 FPS 图表（绿色柱状图表示高 FPS，红色表示卡顿）46。
    - **Rendering 面板**：开启 FPS Meter 实时监控
    - requestAnimationFrame api

 ```js
 requestAnimationFrame(() => {
       const start = performance.now();
       requestAnimationFrame(() => {
         const fps = 1000 / (performance.now() - start);
         console.log('FPS:', fps);
       });
     });
```

### **资源加载指标** Speed Index

**Speed Index (速度指数)**

- **定义/用途**：综合计算页面内容可视部分的填充速度（单位：毫秒），数值越低越快。
- **重要性**：量化用户感知的“视觉完成度”，优于单纯的首屏时间。
- **推荐标准**：≤3.4 秒（良好），>5.8 秒（需优化）。
- **测量方式**：
  - **工具**：WebPageTest（通过视频帧分析）、Lighthouse。

### **网络相关指标**

1. **DNS Lookup Time**
    - **获取方式**：

      ```javascript
      performance.getEntriesByType('navigation')[0].domainLookupEnd - 
      performance.getEntriesByType('navigation')[0].domainLookupStart
      ```

2. **TTFB (Time to First Byte)**
    - **定义**：从请求发出到收到第一个字节的时间
    - **优化建议**：CDN、服务端缓存

### 最佳实践

1. **优先级建议**：LCP、FID、CLS 是 Google 官方核心指标，需优先优化。
2. **测量工具对比**

| 工具/API                         | 适用场景      | 特点                                   |
| ------------------------------ | --------- | ------------------------------------ |
| **Lighthouse**                 | 开发环境评分    | 提供完整优化建议                             |
| **Chrome DevTools**            | 实时性能分析    | 支持火焰图、网络瀑布图                          |
| **WebPageTest**                | 多地点真实网络测试 | 支持视频录制和高级指标                          |
| **RUM (Real User Monitoring)** | 生产环境监控    | 采集真实用户数据（如 Google Analytics， Sentry） |

3.现代 API

```javascript
// 使用 Navigation Timing API 获取完整时间线
const [pageNav] = performance.getEntriesByType('navigation');
console.log({
  DNS: pageNav.domainLookupEnd - pageNav.domainLookupStart,
  TCP: pageNav.connectEnd - pageNav.connectStart,
  TTFB: pageNav.responseStart,
  FCP: performance.getEntriesByName('first-contentful-paint')[0].startTime
});

// 使用 Paint Timing API
performance.getEntriesByType('paint').forEach(entry => {
  console.log(`${entry.name}: ${entry.startTime}ms`);
});
```
