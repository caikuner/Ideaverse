### flex:1

flex：原始默认值是 `flex: 0 1 auto`

```css
flex: 1;
/* 等价于 */
flex-grow: 1;
flex-shrink: 1;
flex-basis: 0%;
```

1. **`flex-grow: 1`（扩展比例）**

- **作用**：当父容器有 **剩余空间** 时，该元素会 **按比例分配剩余空间**。
- **示例**：
  - 如果所有子元素都是 `flex: 1`，它们会 **均分剩余空间**。
  - 如果一个子元素是 `flex: 2`，另一个是 `flex: 1`，则前者占 **2/3**，后者占 **1/3**。

  **2. `flex-shrink: 1`（收缩比例）**

- **作用**：当父容器 **空间不足** 时，该元素会 **按比例收缩**。
- **示例**：
  - 如果子元素总宽度超过父容器宽度，`flex-shrink: 1` 会让它们 **等比例缩小**。
  - 如果某个子元素是 `flex-shrink: 0`，它 **不会收缩**（保持固定大小）。

**3. `flex-basis: 0%`（初始基准大小）**

- **作用**：指定元素的 **初始大小**，`0%` 表示 **不依赖内容宽度**，完全由 `flex-grow` 和 `flex-shrink` 分配空间。
- **对比**：
  - `flex-basis: auto`：元素先按内容宽度计算，再分配剩余空间。
  - `flex-basis: 0%`：直接忽略内容宽度，完全按比例分配。

---

### **`flex: 1` 的实际效果**

- **空间充足时**：元素会 **扩展**，占满剩余空间
- **空间不足时**：元素会 **收缩**，避免溢出
- **与其他 `flex` 值比较**：
  - `flex: 0` → 不扩展也不收缩（固定大小）。
  - `flex: none` → 等价于 `flex: 0 0 auto`（完全固定，不伸缩）。
  - `flex: auto` → 等价于 `flex: 1 1 auto`（按内容宽度伸缩）。

---

### 对比 `flex: auto`

| 属性             | 等价展开         | `flex-basis` 行为 | 空间分配逻辑                         | 典型应用场景             |
| ---------------- | ---------------- | ----------------- | ------------------------------------ | ------------------------ |
| **`flex: 1`**    | `flex: 1 1 0%`   | 初始尺寸为 `0%`   | **完全按比例分配**，忽略内容宽度     | **均分剩余空间**         |
| **`flex: auto`** | `flex: 1 1 auto` | 初始尺寸为 `auto` | **先按内容宽度计算，再分配剩余空间** | **内容敏感**的自适应布局 |
| 默认值           | flex: 0 1 auto   | 初始尺寸为 `auto` | 只会缩短自己来适应，不会撑大         |                          |

**`flex:1` 强制均分，`flex:auto` 尊重内容**

- 用 `flex: 1` 当需要 **严格按比例分配空间**（如导航菜单均分）。
- 用 `flex: auto` 当需要 **兼顾内容宽度**（如输入框和按钮组合）。
