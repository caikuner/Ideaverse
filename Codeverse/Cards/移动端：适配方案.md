移动端适配是为了让网页或应用在不同尺寸和分辨率的移动设备上都能提供一致且良好的用户体验。以下是几种常见的移动端适配方案：

## 百分比布局

- **原理**：通过将元素的宽度、高度、边距、内边距等属性设置为百分比值，使其相对于父元素进行自适应调整。
- **优点**：能够根据父容器的大小自动调整元素尺寸，适应不同屏幕宽度的设备，简单易用，兼容性好。
- **缺点**：对于复杂的布局，可能需要多层嵌套和精细的计算来实现理想效果，且高度的百分比布局可能会出现一些意外情况，因为高度通常取决于内容的多少。

## 弹性布局（Flexbox）

- **原理**：通过 `display: flex` 属性将容器设置为弹性布局，然后使用 `flex` 相关的属性来控制子元素的排列方式、对齐方式和伸缩比例。
- **优点**：提供了一种灵活且强大的布局方式，能够轻松实现水平或垂直居中、等分布局、响应式布局等常见需求，大大简化了布局的代码和逻辑。
- **缺点**：对于一些不支持弹性布局的旧浏览器，可能需要添加额外的兼容代码。（但目前基本可以直接使用了）

## 网格布局（Grid）

- **原理**：将页面划分为行和列的网格，通过指定元素在网格中的位置和跨度来进行布局。
- **优点**：能够实现更复杂、更精确的布局，尤其适合需要对齐和分栏的场景，对于响应式设计也有很好的支持，可以方便地根据不同屏幕尺寸调整网格的行数和列数。
- **缺点**：语法相对复杂，部分旧浏览器支持有限，使用时需要注意兼容性。

## 媒体查询

- **原理**：通过 `@media` 规则，根据不同的媒体类型（如屏幕、打印等）和设备特性（如屏幕宽度、高度、分辨率等）来应用不同的样式。
- **优点**：可以针对不同的设备尺寸和特性进行精确的样式调整，实现高度定制化的响应式设计。
- **缺点**：随着设备种类的增多，需要编写大量的媒体查询代码，维护成本较高，且如果媒体查询的断点设置不合理，可能会导致布局在某些设备上出现问题。

## 响应式图片

- **原理**：使用 `srcset` 和 `sizes` 属性来提供不同分辨率的图片资源，让浏览器根据设备的屏幕分辨率和视口大小选择合适的图片进行加载。
- **优点**：能够确保在不同设备上都能加载合适分辨率的图片，避免图片过大或过小影响页面性能和美观度。
- **缺点**：需要准备多个不同分辨率的图片，增加了开发和维护的工作量，且对于一些不支持 `srcset` 和 `sizes` 属性的旧浏览器，需要提供备用方案。

## Rem 布局

- **原理**：`rem` 是相对于根元素（`html`）字体大小的单位。通过设置根元素的字体大小，然后使用 `rem` 来定义其他元素的尺寸，当根元素字体大小改变时，所有使用 `rem` 单位的元素都会相应地进行缩放。
- **优点**：可以实现整体页面的等比例缩放，适应不同屏幕尺寸的设备，同时也便于进行全局的样式调整和管理。
- **缺点**：需要借助 JavaScript 来根据屏幕宽度动态调整根元素的字体大小，且对于一些复杂的布局，可能需要进行一些额外的计算和调整。

在实际开发中，通常会根据项目的具体需求和特点，综合使用多种适配方案，以达到最佳的移动端适配效果。

## H5 页面的横竖屏切换，需要做哪些处理

- CSS 样式调整
- **媒体查询**：使用 CSS 媒体查询来检测屏幕的方向，针对竖屏和横屏设置不同的样式，包括元素的布局、尺寸、字体大小等。

```
/* 竖屏 */
@media screen and (orientation: portrait) {}

/* 横屏 */
@media screen and (orientation: landscape) {}
```

- 调整相应布局等
- **弹性布局**：多采用弹性盒布局（Flexbox）或网格布局（Grid）等现代布局方式，使页面元素能够根据屏幕空间自动调整位置和大小，实现更灵活的布局。
- **相对单位**：在设置样式时，尽量使用相对单位，如百分比、em、rem 等，避免使用固定像素值，这样可以使页面元素在不同屏幕尺寸和方向下能够自适应调整。
- **图片和媒体元素处理**：要确保它们在横竖屏切换时能够正确显示和适应屏幕。可以通过设置 `max-width` 和 `max-height` 属性，让图片和视频在不同屏幕方向下按比例缩放，避免出现变形或超出屏幕范围的情况。
- JavaScript 事件处理
- **获取屏幕方向：** `**window.screen.orientation.angle**`**,** `**0**`**表示竖屏，**`**90**`**或**`**-90**`**表示横屏（不同设备可能略有差异）**
- **监听屏幕方向变化事件**：通过 `orientationchange` 事件监听屏幕方向的变化。

```
window.addEventListener('orientationchange', function(){
  console.log(window.screen.orientation)
  const angle = window.screen.orientation.angle
  if (angle === 0) {
    // 竖屏
  } else if (angle === 90 || angle === - 90) {
    // 横屏
  }
})
```

- **执行相应的操作**：在屏幕方向变化事件处理函数中，可以编写代码来执行一些特定的操作，如重新调整页面布局、加载不同的资源、更新界面元素等。
- 其他考虑事项
- **兼容性处理**：不同设备和浏览器对横竖屏切换的支持可能存在差异，需要进行充分的测试，确保页面在各种主流设备和浏览器上都能正常切换和显示。
- **用户体验优化**：考虑在横竖屏切换时添加一些过渡效果，如淡入淡出、滑动等，使页面切换更加流畅，提升用户体验。同时，要注意保存用户在当前屏幕方向下的操作状态，以便在切换后能够恢复，避免用户重新操作。
