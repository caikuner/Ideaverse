| **特性**   | **WebSocket**                 | **HTTP**                                 |
| -------- | ----------------------------- | ---------------------------------------- |
| **协议类型** | 全双工通信协议                       | 半双工（请求 - 响应模型）                           |
| **连接特性** | 持久化连接<br>（单 TCP 连接，一次握手，持续通信） | 短连接（每次请求新建 TCP 连接,<br>keep-alive 可短暂长连接） |
| **通信方式** | 双向实时通信（服务端可主动推送）              | 单向通信（客户端发起请求，服务端响应）                      |
| **头部开销** | 初始握手后，后续头部很小 (2～10B)          | 每次请求携带完整 HTTP 头部（数百 B）                   |
| **适用场景** | 实时聊天、在线游戏、股票行情推送              | 网页浏览、API 调用、文件下载                         |
| **延迟**   | 低（无频繁连接建立开销）                  | 较高（每次请求需握手）                              |
| **兼容性**  | 需浏览器和服务端支持                    | 所有设备和服务器均支持                              |
| **数据格式** | 支持二进制帧和文本帧                    | 文本（HTTP 头部） + 任意 Body 格式                 |
| **示例应用** | 微信、Slack、协同编辑、实时监控            | 网页加载、RESTful API 调用                      |
