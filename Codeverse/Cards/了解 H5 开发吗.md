移动 H5 开发需兼顾**多端兼容性**、**性能体验**和**原生交互能力**，以下是关键技术与实践方案：

---

### **1. 核心适配方案**

| **挑战**               | **解决方案**                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| **屏幕适配**           | - REM + Flex 布局（PostCSS-pxtorem）<br>- Viewport 动态计算（`vw/vh` + 降级方案） |
| **iOS/Android 差异**   | - 统一交互规范（避免依赖 OS 特性）<br>- 检测平台动态加载样式（如 `-webkit-overflow-scrolling`） |
| **1px 边框问题**       | `transform: scale(0.5)` + 伪元素                                            |

**代码示例（动态 Viewport）**：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
<script>
  document.documentElement.style.fontSize = document.documentElement.clientWidth / 10 + 'px';
</script>
```

---

### **2. 性能优化体系**

#### **(1) 加载速度**

- **资源压缩**：WebP 图片 + Brotli 压缩（Nginx 配置）
- **预加载**：`<link rel="preload" href="critical.css">`
- **懒加载**：IntersectionObserver 实现图片/组件按需加载

#### **(2) 渲染性能**

| **问题**          | **优化手段**                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| **列表卡顿**      | 虚拟滚动（react-window/vue-virtual-scroller）                               |
| **动画掉帧**      | CSS3 动画（`transform/opacity`） + `will-change`                            |
| **输入延迟**      | 防抖处理 + 避免 300ms 点击延迟（`<meta name="fastclick" content="enabled">`）|

**关键指标**：
- 首屏时间 ≤1s（3G 网络）
- FPS ≥55（Performance API 监控）

---

### **3. 原生交互能力扩展**

#### **(1) JS Bridge 通信**

```javascript
// 调用原生相册
window.JSBridge?.getPhotos({ count: 5 })
  .then(photos => console.log(photos));

// 监听原生事件
document.addEventListener('NativeBackPressed', handleBack);
```

#### **(2) 跨端方案选型**

| **场景**           | **推荐方案**                      | **特点**                          |
|--------------------|----------------------------------|-----------------------------------|
| **轻量 H5**        | 纯 Web 开发（PWA）               | 低开发成本，更新快                |
| **高性能需求**     | React Native/Weex               | 接近原生体验                      |
| **快速迭代**       | 小程序容器（Uni-app/Taro）       | 跨端发布，生态丰富                |

---

### **4. 调试与监控**

#### **(1) 真机调试工具**

- **iOS**：Safari Develop Mode + Web Inspector
- **Android**：Chrome Remote Debugging
- **跨平台**：Eruda（移动端控制台）

#### **(2) 线上监控**

- **异常捕获**：Sentry（支持 SourceMap 解析）
- **性能上报**：Navigation Timing API + FP/FCP 监控
- **用户行为**：Session Replay（LogRocket）

---

### **5. 前沿技术探索**

- **WebAssembly**：高性能计算（如 H5 游戏）
- **Web Components**：跨框架组件复用
- **PWA**：离线可用 + 桌面图标（需 HTTPS）

---

## **避坑指南**

1. **避免 `scroll` 事件滥用**：用 `IntersectionObserver` 替代。
2. **iOS 弹性滚动**：`-webkit-overflow-scrolling: touch` 可能导致内存泄漏。
3. **Android 键盘遮挡**：动态调整 `viewport` 或使用 `scrollIntoView`。

---

## **总结**

移动 H5 开发需掌握：
✅ **响应式布局体系**
✅ **性能优化闭环**（加载→渲染→交互）
✅ **原生桥接能力**（JSBridge/WebView 扩展）
✅ **数据驱动监控**（异常→性能→业务指标）

**未来趋势**：
- **Web 原生能力增强**（如 WebGPU、WebTransport）
- **跨端技术收敛**（小程序容器 → 标准化 Web 能力）
