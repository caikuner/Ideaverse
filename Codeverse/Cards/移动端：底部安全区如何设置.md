在移动端 H5 页面开发中，底部安全区（Safe Area）的设置是为了避免内容被设备的底部指示条（如 iPhone 的 Home Indicator）或圆角遮挡。

## 使用 CSS env() 函数

`env(safe-area-inset-bottom)` 是一个 CSS 环境变量，用于处理移动设备底部安全区域（Safe Area）的间距问题，特别是在有底部指示条（如 iPhone 的 Home Indicator）或圆角屏幕的设备上。

```css
body {
  padding-bottom: env(safe-area-inset-bottom);
  /* 或者使用 constant() 作为兼容性回退 */
  padding-bottom: constant(safe-area-inset-bottom);
}
```

必要前提：在 meta viewport 标签中添加 viewport-fit=cover：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0, viewport-fit=cover">
```

工作原理

1. 当在全面屏设备（如 iPhone X 及以上）上时，`env(safe-area-inset-bottom)` 会返回设备底部不安全区域的像素值
2. 在非全面屏设备上，这个值通常为 0
3. 需要与 `viewport-fit=cover` 配合使用才能生效

## 常见应用场景

### 1. 固定底部导航栏

```css
.bottom-nav {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  padding-bottom: env(safe-area-inset-bottom);
  background: white;
}
```

### 2. 全屏页面底部留白

```css
body {
  padding-bottom: env(safe-area-inset-bottom);
}
```

### 3. 底部按钮组

```css
.button-group {
  margin-bottom: env(safe-area-inset-bottom);
}
```

## 兼容性写法

为了兼容不同版本的 iOS 浏览器，通常需要同时使用 `constant()` 和 `env()`：

```css
.element {
  padding-bottom: constant(safe-area-inset-bottom); /* 旧版iOS */
  padding-bottom: env(safe-area-inset-bottom); /* 新版iOS */
}
```

## 注意事项

1. 这个特性主要针对 iOS 设备，Android 设备的实现可能不同
2. 在开发时可以使用 Safari 的响应式设计模式测试不同设备的效果
3. 如果不需要全屏显示，可以不使用 `viewport-fit=cover`，这时安全区域变量将不起作用

## 实际值示例

在 iPhone X 上：
- `env(safe-area-inset-bottom)` 的值通常是 34px
- 在横屏模式下，这个值可能会变化

## 完整示例

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
  <style>
    body {
      margin: 0;
      padding: 0;
      padding-bottom: env(safe-area-inset-bottom);
    }
    
    .footer {
      position: fixed;
      bottom: 0;
      left: 0;
      right: 0;
      height: 50px;
      background: #333;
      color: white;
      padding-bottom: env(safe-area-inset-bottom);
    }
  </style>
</head>
<body>
  <!-- 页面内容 -->
  <div class="footer">底部内容</div>
</body>
</html>
```

## 注意事项

1. `env()` 和 `constant()` 的区别：
   - 新版本浏览器使用 `env()`
   - 旧版本使用 `constant()`
   - 可以同时使用作为兼容

2. 某些 Android 设备可能需要特殊处理，因为它们的安全区实现可能与 iOS 不同
3. 在开发过程中，可以使用浏览器的开发者工具模拟不同设备的安全区进行测试
