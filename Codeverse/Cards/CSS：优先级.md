## CSS 样式优先级 权重问题

### 样式的引入顺序

页面是加载解析渲染的，如果其他情况一样，后写的样式肯定要覆盖前面的【后者覆盖前者】

- 先看来源
    - 默认继承
    - HTML 默认
    - 浏览器默认
    - 开发者定义
    - 用户自定义
- 我们主要关注四种自定义引入方式
    - @import 的样式由于在样式的最顶层，先引用
    - 外部样式表
    - 内嵌样式表
    - 内联样式
- 另外，`!important` 声明将拥有最高优先级，如果有多个，也会按照上面的来源和引入方式的顺序，进行后者覆盖前者

### 选择器优先级算法

理解了样式的继承、来源和引入方式之后，我们将权重的计算方法。

#### 基本选择器权重

我们在内联样式中写样式直接就命中元素了不需要选择器，样式表 (内嵌样式表和外部样式表) 中定义的样式则是通过选择器。

而 CSS 中有 5 种基本的选择器、2 种伪类伪元素选择器、4 种组合选择器，搭配 1 起来更多，会出现多个不同类型的选择器同时为一个对象设置样式的情况。

- ID 选择器， 如 `#id` {}
- 类选择器， 如 .class {}
- 属性选择器， 如 a [href="segmentfault.com"]{}
- 伪类选择器， 如 :hover {} :first-child
- 伪元素选择器， 如 ::before {}
- 标签选择器， 如 span {}
- 通配选择器， 如 *{}
- 紧邻兄弟选择器 +
- 任意兄弟选择器 ~
- 直接子选择器 >
- 后代选择器 空格

所以为选择器引入了权重。

只是，权重并不是简单相加，早期它们的进制是 256，会出现 256 个 class 覆盖 1 个 id 的情况，不过目前浏览器提高了权值进制甚至大于 65536，所以正常来说很难产生进位，不会覆盖了。区分级别才是重点。

- !important 优先级别最高，可以理解为：1,0,0,0,0
- 内联样式不需要选择器：优先级加权值 **1,0,0,0**
- ID 选择器：优先级加权值为 **0,****1,0,0**
- 类选择器，属性选择器，伪类选择器：优先级加权值为 **0,****0,1,0**
- 标签选择器, 伪元素选择器：优先级加权值为 **0,****0,0,1**
- 通配选择器 (*)：优先级加权值为 **0,****0,0,0**

依此方法计算中的加权值：（不是相加！！11 个类选择器也不会大于 1 个 ID 选择器！！）

- 可以把权重值看成三位 `a,b,c`，计算总权重是单独计算 a b c 各自的总和，简单说就是各自计数。
- 计算完成后，最后依次比较 a b c：a 大的级别高，a 相同才会去比较 b，b 相同才会去比较 c
- 例如：
- 11 个类选择器 0 11 0
- 1 个 ID 选择器 1 0 0
- 后者权重更高
- 如果**权重分值相同，则根据位置关系来进行判断，靠近对象的样式就应有高的优先级 (比如 子 比 孙 更近、兄弟比子更近)**。

#### 组合选择器

对于组合选择器，我们要知道，也是先通过基本选择器去找的：

- 肯定先是按照 基本选择器的权重
- 当然组合选择器大概率会使用同一个基本选择器，像下面一样，然后注意：
- 兄弟选择器： 直接兄弟 + 与 任意兄弟~ 权重相同，完全按照加载顺序，即**后写的覆盖前面的样式**
- 后代选择器： `直接孩子>` 与 任意后代   权重相同，完全按照加载顺序，即**后写的覆盖前面的样式**

```
// 找兄弟
.first + p {
  color: green;
}

.first ~ p {
  color: blue;
} // 后写，生效

// 找后代
.first > p {
  color: bisque
}

.first p {
  color: black
} // 后写，生效
```

### 小结

- **!important > 内联样式** > **ID 选择器** **>** **类选择器 = 属性选择器 =** **伪类选择器 >** **标签选择器** **= 伪元素选择器** **>** **通配选择器** >**HTML 和浏览器默认样式** > 默认**继承来的**
- 组合选择器直接的兄弟/孩子 并没有优先级区分，完全是后者覆盖前者
- 权重相同，位置近优先；后者覆盖前者
