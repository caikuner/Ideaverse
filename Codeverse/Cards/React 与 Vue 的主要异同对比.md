## 相同点

1. **组件化开发**：都采用组件化思想构建应用
2. **虚拟 DOM**：都使用虚拟 DOM 来提高渲染效率
3. **响应式数据**：都提供了数据驱动视图的机制
4. **生态系统**：都有丰富的周边生态和工具链
5. **单文件组件**：都支持将模板、逻辑和样式放在单个文件中（React 通过 JSX，Vue 通过 `.vue` 文件）

## 核心差异

### 1. 设计哲学

- **React**：推崇函数式编程，主张 "UI 是状态的函数 "，更贴近原生 js 语法
- **Vue**：更倾向于渐进式框架，提供模版语法等更多开箱即用的功能

### 2. 数据绑定

| 特性         | React                             | Vue                         |
| ------------ | --------------------------------- | --------------------------- |
| 数据绑定方式 | 单向数据流                        | 双向数据绑定（v-model）     |
| 状态管理     | 需要手动调用 setState 或 useState | 自动响应式（data/computed） |
| 更新触发     | 显式调用 setState                 | 自动追踪依赖并更新          |

### 3. 模板 vs JSX

| 特性     | React        | Vue                  |
| -------- | ------------ | -------------------- |
| 模板语法 | 使用 JSX     | 使用 HTML-based 模板 |
| 灵活性   | 更高的灵活性 | 更直观的模板语法     |
| 学习曲线 | 需要学习 JSX | 对新手更友好         |

### 4. 状态管理

| 特性         | React                       | Vue                 |
| ------------ | --------------------------- | ------------------- |
| 核心状态管理 | useState/useReducer (Hooks) | data/computed/watch |
| 全局状态管理 | Redux/MobX                  | Vuex/Pinia          |
| 状态更新方式 | 不可变数据                  | 可变数据            |

### 5. 生命周期

| 阶段   | React (函数组件)                    | Vue 3 (Composition API) |
| ------ | ----------------------------------- | ----------------------- |
| 创建前 | -                                   | setup()                 |
| 挂载前 | -                                   | onBeforeMount           |
| 挂载后 | useEffect(() => {}, [])             | onMounted               |
| 更新前 | -                                   | onBeforeUpdate          |
| 更新后 | useEffect(() => {})                 | onUpdated               |
| 卸载前 | useEffect(() => { return cleanup }) | onBeforeUnmount         |
| 卸载后 | -                                   | onUnmounted             |

### 6. 性能优化

| 特性         | React                            | Vue                                |
| ------------ | -------------------------------- | ---------------------------------- |
| 组件更新机制 | 默认全部子组件可能重新渲染       | 更精确的依赖追踪，减少不必要的更新 |
| 优化手段     | React.memo, useMemo, useCallback | 自动缓存计算属性，v-once 等指令    |

### 7. 学习曲线

- **React**：需要理解 JSX、不可变数据、Hooks 等概念
- **Vue**：模板语法更接近传统 HTML，API 设计更直观

## 适用场景

### React 更适合

- 大型复杂应用
- 需要高度自定义的项目
- 跨平台开发（React Native）
- 团队偏好函数式编程

### Vue 更适合

- 快速原型开发
- 中小型项目
- 需要渐进式采用框架的项目
- 团队偏好声明式模板和更少的样板代码

## 总结

React 提供了更大的灵活性和控制力，但需要开发者做更多决策；Vue 提供了更多开箱即用的功能，让开发者能更快上手。选择哪一个取决于项目需求、团队偏好和开发风格。
