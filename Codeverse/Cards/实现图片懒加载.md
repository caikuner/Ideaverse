方式 二：js 延迟设置 src

图片懒加载的核心原理是：**仅当图片进入或即将进入可视区域时，才加载真实图片资源**。这通过以下步骤实现：

1. 将所有需要懒加载的图片的 `src` 属性替换为 `data-src`（或其他自定义属性）
2. 监听滚动事件，判断图片是否进入可视区域
3. 当图片进入可视区域时，将 `data-src` 的值赋给 `src` 属性，触发图片加载

### getBoundingClientRect

该方法返回元素的大小及其相对于视口的位置。

```javascript
// 获取所有需要懒加载的图片
const lazyImages = document.querySelectorAll('img[data-src]');

// 图片加载函数
function loadImage(img) {
  const src = img.getAttribute('data-src');
  if (!src) return;
  
  img.src = src;
  img.removeAttribute('data-src');
}

// 检查图片是否在可视区域内
function isInViewport(img) {
  const rect = img.getBoundingClientRect();
  return (
    rect.top <= (window.innerHeight || document.documentElement.clientHeight) &&
    rect.bottom >= 0 &&
    rect.left <= (window.innerWidth || document.documentElement.clientWidth) &&
    rect.right >= 0
  );
}

// 加载可视区域内的图片
function lazyLoad() {
  lazyImages.forEach(img => {
    if (isInViewport(img)) {
      loadImage(img);
    }
  });
}

// 添加滚动事件监听（使用节流优化）
function throttle (fn, delay) {
  let timer = null
  return function (…args) {
      const context = this
      if (timer) return

        timer = setTimeout(()=>{
            fn.apply(context, args)
            timer = null
        }, delay)
  }
}

const throttledLazyload = throttle(lazyload, 200)
window.addEventListener('scroll', throttledLazyload);

// 初始加载
lazyLoad();
```

## IntersectionObserver API

 `IntersectionObserver` API：提供了一种异步观察目标元素与其祖先元素或顶级文档视窗 (viewport) 交叉状态的方法。祖先元素与视窗 (viewport) 被称为根 (root)。
  当一个 IntersectionObserver 对象被创建时，其被配置为监听根中一段给定比例的可见区域。

```javascript
// 获取所有需要懒加载的图片
const lazyImages = document.querySelectorAll('img[data-src]');

// 创建观察器
const observer = new IntersectionObserver(
    (entries, observer) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) { // 出现交叉
        
          const img = entry.target;
          img.src = img.getAttribute('data-src');
          img.removeAttribute('data-src');
          
          observer.unobserve(img); // 取消观察
        }
      });
    }, 
    {
      rootMargin: '0px 0px 100px 0px' // 提前100px加载
    }
);


// 开始观察所有图片
lazyImages.forEach(img => {
  observer.observe(img);
});
```

## 面试要点

1. **实现原理**：
   - 替换 `src` 为 `data-src`
   - 监听滚动事件或使用 `IntersectionObserver`
   - 判断元素是否在可视区域内
   - 动态加载真实图片

2. **性能优化**：
   - 使用节流（throttle）优化滚动事件
   - 使用 `IntersectionObserver` 代替滚动监听（更高效）
   - 设置预加载区域（rootMargin）

3. **兼容性处理**：
   - 提供传统滚动监听和 `IntersectionObserver` 两种方案
   - 考虑图片加载失败的情况（可添加 `onerror` 处理）

4. **扩展功能**：
   - 支持占位图（placeholder）
   - 支持加载动画
   - 支持响应式图片（srcset）

## 示例 HTML 结构

```html
<img data-src="real-image.jpg" src="placeholder.jpg" alt="示例图片" class="lazy-image">
```
