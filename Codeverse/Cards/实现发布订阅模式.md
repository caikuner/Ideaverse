### 发布 - 订阅 模式

```
[Publisher] → [Event Channel] → [Subscriber]
                 (Message Broker)
```

### 对比观察者模式

| 特性         | 观察者模式           | 发布 - 订阅模式        |
| ---------- | --------------- | ---------------- |
| **耦合关系**   | 观察者直接知道被观察对象    | 发布者与订阅者互不可见      |
| **通信方式**   | 直接方法调用          | 通过消息代理/事件总线      |
| **消息传递方向** | 单向（被观察者→观察者）    | 多向（发布者→通道→订阅者）   |
| **典型应用场景** | GUI 事件处理、组件状态更新 | 微服务通信、跨模块事件处理    |
| **实现复杂度**  | 简单              | 复杂（需要中间件）        |
| **生命周期管理** | 需要手动维护订阅关系      | 通常由中间件管理         |
| **实时性**    | 更高（直接触发）        | 较低（存在消息队列时可能有延迟） |

### 实现

```js
// 发布-订阅模式：和事件总线基本一致，不过一般是通知所有订阅，而不是触发单个事件
class EventBus {
  constructor() {
    // 使用Map存储事件与回调的依赖映射关系
    this.deps = new Map();
  }

  // 订阅事件（支持多个处理器），通过事件回调的形式，可以避免硬编码 update 函数
  subscribe(eventType, callback) {
    if (!this.deps.has(eventType)) {
      this.deps.set(eventType, []);
    }
    this.deps.get(eventType).push(callback);

    return () => {
      // 用于清除订阅
      this.unsubscribe(eventType, callback);
    };
  }

  unsubscribe(eventType, callback) {
    if (!this.deps.has(eventType)) {
      return;
    }
    const index = this.deps.get(eventType).indexOf(callback);
    if (index !== -1) {
      this.deps.get(eventType).splice(index, 1);
    }
  }

  // 发布事件（支持传参）
  publish(eventType, ...args) {
    const callbacks = this.deps.get(eventType) || [];
    callbacks.forEach(callback => {
      try {
        callback(...args);
      } catch (e) {
        console.error(`事件处理错误 [${eventType}]:`, e);
      }
    });
  }
}
```

```js

// 使用示例：股票市场价格监控的例子
class StockMarketBus extends EventBus{
  constructor(price) {
    super()
    this.stockPrice = price
  }
}

// 发布者
const stockMarketBus = new StockMarketBus(100)

stockMarketBus.subscribe('price', (price) => {
  // 订阅者：价格更新处理
  if (stockMarketBus.stockPrice !== price) {
    console.log('股价改变了！')
  }
})

stockMarketBus.subscribe('price', (price) => {
  // 订阅者：价格过高报警处理
  if (price > 150) {
    console.error('发送邮件预警：股价过高！')
  }
})

// 发布价格,触发所有订阅
stockMarketBus.publish('price', 100)
stockMarketBus.publish('price', 200)

```
