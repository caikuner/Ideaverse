JS 中，对象和数组可以解构赋值。`const obj = {a:1, b: 2}; const {a} = obj`

> 面试题：如何让 `const [a, b] = {a:1, b:2}` 成功

在 JavaScript 中，直接使用 `const [a, b] = {a:1, b:2}` 会失败，因为数组解构赋值 (`[]`) 需要右侧是一个可迭代对象（如数组、字符串、Set、Map 等），而普通对象 `{a:1, b:2}` 默认是不可迭代的。

### 解决方案

#### 方法 1：将对象转换为可迭代对象

让对象实现迭代器协议，使其可以被数组解构：

```javascript
const obj = { a: 1, b: 2 };

// 使对象可迭代
obj[Symbol.iterator] = function* () {
  yield this.a;
  yield this.b;
};

const [a, b] = obj; // 成功：a=1, b=2
```

#### 方法 2：使用 `Object.values()`

更简单的方法是先获取对象的值数组：

```javascript
const { a, b } = { a: 1, b: 2 }; // 对象解构
// 或者
const [a, b] = Object.values({ a: 1, b: 2 }); // 转为数组后解构
```

#### 方法 3：使用默认数组解构

如果只是想获取对象的前几个值：

```javascript
const [a, b] = Object.values({ a: 1, b: 2 }); // a=1, b=2
```

### 为什么原始写法不行？

因为 `{a:1, b:2}` 不是可迭代对象，而数组解构 `[]` 需要右侧实现 `Symbol.iterator`。对象解构应该使用 `{}` 语法：

```javascript
// 正确的对象解构
const { a, b } = { a: 1, b: 2 }; // a=1, b=2
```

### 总结

- **对象解构**：使用 `const {a, b} = {a:1, b:2}`
- **数组解构对象**：需要先转换为数组 `Object.values()` 或使对象可迭代

选择哪种方式取决于你的具体需求。
