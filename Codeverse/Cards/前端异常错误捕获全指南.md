前端异常捕获是保证应用稳定性的关键环节。以下是针对不同错误类型和框架的完整捕获方案：

## **一、全局 JavaScript 错误捕获**

### **1. 常规 JavaScript 错误**

#### **(1) `window.onerror`（全局 JS 错误）**

```js
window.onerror = function(message, source, lineno, colno, error) {
  console.error('全局错误:', { message, source, lineno, colno, error });
  return true; // 阻止默认错误提示
};
```

**捕获范围**：
- 同步错误（如 `undefined variable`）
- 部分异步错误（如 `setTimeout` 内同步错误）

**⚠️ 限制**：
- 无法捕获 `Promise` 未处理的 `rejection`。
- 如何捕获 `跨域脚本` 的错误：
	- 脚本加上 `crossorigin` 属性 `<script src="https://other-domain.com/app.js" crossorigin></script>`
	- 且服务器设置 `Access-Control-Allow-Origin`。

#### **(2) `window.addEventListener('error')`（资源加载错误）**

```js
window.addEventListener('error', (event) => {
  if (event.target instanceof HTMLLinkElement || event.target instanceof HTMLScriptElement || event.target instanceof HTMLImageElement) {
    console.error('资源加载失败:', event.target.src || event.target.href);
  } else {
    console.error('全局错误:', event.error || event.message);
  }
}, true); // 使用捕获阶段
```

**捕获范围**：
- `<img>`, `<script>`, `<link>` 等资源加载失败。
- 比 `window.onerror` 更全面（能捕获资源错误），但是 safari 打印的堆栈没有 onerror 完整。

---

### **2. 未处理的 Promise 错误**

#### **(1) `unhandledrejection`（浏览器）**

```js
window.addEventListener('unhandledrejection', (event) => {
  console.error('未处理的 Promise 错误:', event.reason);
  event.preventDefault(); // 阻止默认控制台报错
});
```

**捕获范围**：
- 所有未被 `.catch()` 处理的 `Promise.reject()`。

#### **(2) `unhandledRejection`（Node.js）**

```js
process.on('unhandledRejection', (error) => {
  console.error('未处理的 Promise 错误:', error);
});
```

## **二、框架级错误捕获**

### **1. Vue 错误捕获**

#### **(1) `errorCaptured` 生命周期（Vue 2/3）**

```js
// Vue 3
app.config.errorHandler = (err, vm, info) => {
  console.error('Vue 全局错误:', err, info);
};

// Vue 2
Vue.config.errorHandler = (err, vm, info) => {
  console.error('Vue 全局错误:', err, info);
};
```

**捕获范围**：
- 组件渲染/侦听器/生命周期钩子中的错误。

#### **(2) `errorCaptured` 钩子（组件级）**

```js
export default {
  errorCaptured(err, vm, info) {
    console.error('组件内部错误:', err, info);
    return false; // 阻止错误继续向上传播
  }
};
```

---

### **2. React 错误捕获**

#### **(1) `Error Boundary`（React 16+）**

```jsx
class ErrorBoundary extends React.Component {
  state = { hasError: false };

  static getDerivedStateFromError(error) {
    return { hasError: true };
  }

  componentDidCatch(error, info) {
    console.error('React 组件错误:', error, info.componentStack);
  }

  render() {
    if (this.state.hasError) {
      return <h1>Something went wrong.</h1>;
    }
    return this.props.children;
  }
}

// 使用
<ErrorBoundary>
  <MyComponent />
</ErrorBoundary>
```

**捕获范围**：
- 子组件的渲染错误。
- 生命周期方法错误。
- 构造函数错误。

**⚠️ 限制**：
- 无法捕获：
  - 事件处理器错误（需手动 `try/catch`）。
  - 异步代码（如 `setTimeout`）。
  - SSR 错误。

#### **(2) 全局错误（React 17+）**

```js
// 捕获渲染时的全局错误
window.addEventListener('error', (event) => {
  if (event.error?.name?.includes('React')) {
    console.error('React 全局错误:', event.error);
  }
});
```

## **三、网络请求错误捕获**

### **1. `axios` 拦截器**

```js
axios.interceptors.response.use(
  (response) => response,
  (error) => {
    console.error('请求错误:', error.response?.status, error.message);
    return Promise.reject(error);
  }
);
```

### **2. `fetch` 错误处理**

```js
fetch(url)
  .then((response) => {
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    return response.json();
  })
  .catch((error) => {
    console.error('Fetch 错误:', error);
  });
```

## **四、其他关键错误捕获**

### **1. `console.error` 重定向（监控日志）**

```js
const originalConsoleError = console.error;
console.error = (…args) => {
  originalConsoleError(…args);
  sendToErrorMonitoring(args); // 发送到监控系统
};
```

### **2. `Web Worker` 错误**

```js
const worker = new Worker('worker.js');
worker.onerror = (event) => {
  console.error('Worker 错误:', event.message);
};
```

### **3. `iframe` 错误**

```js
const iframe = document.querySelector('iframe');
iframe.contentWindow.onerror = function(message, source, lineno, colno, error) {
  console.error('iframe 错误:', message);
};
```

## **五、错误监控上报方案**

### **1. 手动上报**

```js
function logError(error, context = {}) {
  fetch('/api/log-error', {
    method: 'POST',
    body: JSON.stringify({ error: error.stack, context }),
  });
}
```

### **2. 使用 Sentry / Bugsnag**

```js
// Sentry
import * as Sentry from '@sentry/browser';
Sentry.init({ dsn: 'YOUR_DSN' });

// 手动捕获
try {
  riskyOperation();
} catch (error) {
  Sentry.captureException(error);
}
```

## **总结**

| **错误类型**         | **捕获方式**                                                                 |
|---------------------|----------------------------------------------------------------------------|
| **全局 JS 错误**     | `window.onerror` + `window.addEventListener('error')`                      |
| **未处理 Promise**   | `unhandledrejection`                                                      |
| **Vue 错误**        | `errorHandler` + `errorCaptured`                                          |
| **React 错误**      | `ErrorBoundary` + `componentDidCatch`                                     |
| **网络请求错误**     | `axios 拦截器` / `fetch.catch()`                                          |
| **资源加载错误**     | `window.addEventListener('error', …, true)`（捕获阶段）                  |
| **自定义监控**       | Sentry / Bugsnag / 手动上报 API                                           |

**最佳实践**：
1. **全局兜底**：`window.onerror` + `unhandledrejection`。
2. **框架集成**：Vue/React 使用官方错误边界。
3. **网络监控**：拦截所有 API 错误。
4. **生产环境上报**：接入 Sentry 或类似工具。
