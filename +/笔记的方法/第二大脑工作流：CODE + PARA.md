- CODE + PARA
    - 捕捉 组织  提炼  表达。类似于：输入  组织  输出   成果

| +Starter   | 开始菜单，计划、清单、看板、关注等                                                                   | - 任务管理：滴答清单<br>- 学习：github，极客时间，牛客，leetcode，掘金<br>- 笔记：语雀，**flomo**，onenote，微软便签，手机笔记<br>- 微信读书, Calibre, goodread<br>- Feedbro            |
| ---------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 0-Inputs   | 收集、捕捉 Capture 感兴趣的信息，缓存到同一个工具，每周清空； 自己主动输入的初步卡片笔记，别有任何负担，just card it!  不要想一步创建完美笔记 | - **Zotero**<br>- read it later in obsidian<br>- 简阅<br>- 收藏内容：Cubox，微信收藏，微信文件助手，知乎收藏，掘金收藏，豆瓣，小红书<br>- 浏览器收藏<br>- 视频：哔哩哔哩收藏、关注、稍后再看，youtube |
| 1-4 PARA   | 组织卡片和工作流程、各子目录加上合适的科学分类法，把卡片组织起来                                                    |                                                                                                                                            |
| 5-Outputs  | 提炼卡片精华，输出一个较为完美的、未来的自己想看到的永久笔记/输出内容                                                 |                                                                                                                                            |
| 6-Outcomes | 利用笔记来完成表达，获得成果，这才是真正的得到！                                                            |                                                                                                                                            |
| Timeline   | 闪念笔记 (使用Memos)，日记                                                                   |                                                                                                                                            |
| Whiteboard | 白板，excalidraw，思维导图等结构化的思维工具                                                         |                                                                                                                                            |
| Assets     | 图像等资源文件，一般不需要直接看                                                                    |                                                                                                                                            |
| Templates  | 模板文件                                                                                |                                                                                                                                            |

    - Inbox 内容的整理
    - 阅读书籍、文章
    - 学习视频、教程
- 输出 Outputs                   【思考，归纳，总结】
    - 长青笔记，永久笔记
- 知识地图 Maps
    - 主题笔记，系统性、科学地分类归入知识地图
