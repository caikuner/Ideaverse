- 必须带有情绪化，让用户看到人味，产生情感共鸣
	- 主题共鸣
		- 暴露弱点、缺点
		- 经验感受
	- 内容利他
		- 分清目标人群，做对方想看的
	- 情绪价值
		- 比如自己的成长，以及让用户看到自身的可能性
- 例子
	- 旅行
		- 旅行攻略 + 自身感受 + 抒情文案 + 插图，提供想像空间
	- 打工
		- 打工日常 + 自身感受 + 吐槽文字，引起讨论和打工人共鸣
	- 学习
		- 成长计划 + 自身成长瞬间，成就感 + 激励文字，与用户一起成长
		- eg
			- 打工人的职场蜕变感悟
			- infj 的读书日记，治愈自己
	- 职场（专业型）
		- 职场干货 + 自身成长 + 经验教训分享，为受众提供指导
		- eg
			- 大厂打工三年，我懂得了
	- deepseek（人机版）
		- 信息差 + 解决一个网上具体痛点问题 + 全方位解读
		- eg：
			- 新婚姻法关于房产的划分
