### 胃病分类

### 胃黏膜修复
胃黏膜受损后的修复是一个复杂过程，需3-6个月时间。其修复机制包括：
1. **上皮细胞再生**：胃黏膜表层细胞每3-5天更新一次，但深层修复需更久。
2. **黏液屏障重建**：胃黏液层需稳定分泌碳酸氢盐和糖蛋白，中和胃酸。
3. **微循环改善**：炎症消退后，血流恢复为黏膜提供氧气和营养。
4. **菌群平衡**：肠道菌群紊乱会加剧炎症，补充益生菌可抑制致病菌，促进黏膜免疫修复。

##  **调理期（3-6个月）的行动方案**


#### **一、饮食管理**
**分阶段调整：**
1. **急性炎症期（1-2周）**：  
   - **饮食**：流质/半流质（米油、小米粥、藕粉、山药糊），忌粗纤维。  
   - **蛋白质**：暂时停肉蛋奶，改用低脂植物蛋白（如嫩豆腐、无糖豆浆过滤渣），少量多餐。  

2. **修复期（1-3个月）**：  
   - **饮食**：软烂易消化食物（煮烂的面条、蒸南瓜、炖白菜），逐渐引入低脂鱼类（如鳕鱼）或鸡胸肉泥（若医生允许）。  
   - **忌口**：辛辣、油炸、咖啡、酒精、寒凉水果（如西瓜）。  

3. **巩固期（3-6个月）**：  
   - **逐步恢复**：少量引入低脂牛奶或酸奶（观察耐受性），优先选发酵乳制品（如无糖酸奶）。  
   - **营养强化**：补充锌（南瓜籽、牡蛎）、维生素A（胡萝卜泥）、维生素C（煮熟的彩椒）促进黏膜修复。

**替代方案**：  
- **钙与蛋白质**：若长期忌口肉蛋奶，需通过芝麻酱、嫩豆腐、低草酸绿叶菜（如小白菜）补钙，必要时咨询医生是否需补充剂。  
- **脂肪来源**：以橄榄油、亚麻籽油为主，减少炎症反应。

- **营养替代**
- 逐步恢复

#### **二、中药与营养辅助**
1. **中成药**：  
   - **枫蓼肠胃康颗粒**（含牛耳枫、辣蓼）：清热化湿，饭前半小时服用以调和脾胃气机。  
   - **辅助方剂**：修复期可加用党参10g+白术10g+茯苓15g煮水，健脾益气（需中医辨证）。  

2. **益生菌**：  
   - **地衣芽孢杆菌胶囊**：饭前温水送服，与抗生素间隔2小时以上，持续至少3个月。  

3. **黏膜保护剂**（可选）：  
   - 康复新液（美洲大蠊提取物）含氨基酸与多糖，可促进溃疡愈合，餐前含服。

---

#### **三、运动与情绪调节**
- **运动**：每日30分钟温和运动（如八段锦、散步），避免饭后立即运动。  
- **情绪管理**：压力通过“脑-肠轴”加重症状，建议每日冥想10分钟或腹式呼吸训练。  

---

## **康复后的长期养胃策略**
1. **饮食原则**：  
   - **定时定量**：避免过饥过饱，晚餐七分饱。  
   - **烹饪方式**：蒸、煮、炖为主，避免腌制食品。  
   - **慎用药物**：非必要不用NSAIDs（如布洛芬），改用对乙酰氨基酚。  

2. **持续养护**：  
   - **发酵食品**：纳豆、味噌（无添加剂）、无糖酸奶（乳糖耐受后）。  
   - **药膳**：每周2次四神汤（茯苓+芡实+莲子+山药）炖粥，健脾祛湿。  

3. **监测与预防**：  
   - **定期检查**：每年胃镜检查（尤其有胃炎病史者）。  
   - **幽门螺杆菌筛查**：阳性者及时根治，避免共用餐具。  

##  关键营养素替代（忌肉蛋奶期间）

| 营养素      | 作用     | 替代食物                   |     |
| -------- | ------ | ---------------------- | --- |
| **蛋白质**  | 黏膜修复原料 | 嫩豆腐、藜麦、去麸质燕麦           |     |
| **锌**    | 细胞再生   | 南瓜籽、松子                 |     |
| **维生素A** | 黏液分泌   | 胡萝卜（油煮）、菠菜（焯水）         |     |
| **谷氨酰胺** | 肠黏膜能量  | 高丽菜汁（煮沸去纤维）、骨汤（可选植物汤底） |     |

### **注意事项**
- **忌口过渡**：康复后逐步引入肉蛋奶，每次试一种，观察耐受性（如先试鸡蛋黄，再蛋白）。  
- **紧急处理**：急性胃痛时可用温盐袋热敷中脘穴（肚脐上4寸），缓解痉挛。  

通过系统调理与长期养护，可显著降低复发风险，逐步恢复胃肠健康。
