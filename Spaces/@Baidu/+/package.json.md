
- http://json.schemastore.org/package

- engines 生效方式: (只会在 install 阶段前置检查)
	- .npmrc -> engine-strict=true
	- package.json 中的 **engineStrict** 选项已经废弃，不会生效

```
安装最新的次要版本：你可以说：“给我安装1.2.0版本以及它的小伙伴们吧！”（"package-name": "^1.2.0"）
安装指定主版本的所有版本：你可以这样说：“我要的是2.0.0版本以及它的众多版本！”（"package-name": "^2.0.0"）
安装指定范围内的版本：你可以说：“我要的是1.0.0到2.0.0之间的版本！”（"package-name": ">=1.0.0 <2.0.0"）
安装指定修订版本的所有版本：你可以这样说：“给我安装1.2.3版本以及它的修订版本们！”（"package-name": "~1.2.3"）
安装指定范围内的版本（使用范围号）：你可以说：“我要的是1.2.0到1.4.0之间的版本！”（"package-name": "1.2.0 - 1.4.0"）
```
